Smoother and cleaner. Creating an overlay no longer switches pages: its settings (opacity, visible, click-through, performance) appear right on the Sources page, and windows with an overlay are marked "Overlay on". Fixed pages drawn over each other after creating an overlay. The overlay title bar is a rounded floating bar that shows only while the pointer is on the overlay, together with the performance readout, and no longer flickers. OBS output windows play as smoothly as overlays and have a close button under the pointer that OBS never records. Calls mode and the Calls category are removed: call apps are captured like any other window (under Other); some, like Discord, stop drawing while minimized or completely covered.
