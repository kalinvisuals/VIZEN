What's new

Every version of VIZEN

Downloads and SHA-256 checksums for every version are on GitHub Releases.

0.4.7October 23, 2026Latest
  • VIZEN Connector from the official stores: the Browser page has buttons for the Chrome Web Store (Chrome, Brave) and Microsoft Edge Add-ons, instead of loading the extension in Developer mode. Clearer setup steps, in English and Romanian.
  • VIZEN Connector is published on the Chrome Web Store as well as Microsoft Edge Add-ons: no Developer mode or unpacked extension needed in Chrome, Edge or Brave.
  • Updates: the installer downloaded for an update is deleted once the new version starts, so it no longer takes 56 MB of space.
  • Microsoft Store copy: needs no special permission besides running as a desktop app, and its "Launch at sign-in" entry is removed together with the app.
0.4.6October 18, 2026
  • Automatic updates (Settings → Updates): VIZEN checks vizen.ro and GitHub, verifies each update and installs it only when you confirm. Your settings and data are kept. Install 0.4.6 once by hand; later versions arrive by themselves.
  • Microsoft Store: VIZEN is available in the Microsoft Store; the Store copy is updated by the Store.
0.4.5October 18, 2026
  • VIZEN Connector from Microsoft Edge Add-ons (and from the Chrome Web Store once it is approved) works with VIZEN. An existing connection is updated automatically.
0.4.4October 18, 2026First public release
  • Overlays from any window or cropped region, on top of windowed and borderless games, with click-through, opacity and measured performance.
  • Calls mode: Discord, Zoom, Teams, WhatsApp and browser calls detected; crop each participant.
  • Studio / OBS: clean output windows, compositions, media layers and sponsor schedules.
  • Smart Notes, Smart Draw and the Smart Audio Mixer with Smart Audio Focus.
  • Browser tabs with the VIZEN Connector extension: switch, mute, pop out or mirror any tab live.
  • English and Romanian, dark and light themes. Free and open source under the GNU GPL v3.

Toate versiunile VIZEN

Descărcările și amprentele SHA-256 pentru fiecare versiune sunt pe GitHub Releases.

0.4.723 octombrie 2026Cea mai nouă
  • VIZEN Connector din magazinele oficiale: pagina Browser are butoane pentru Chrome Web Store (Chrome, Brave) și Microsoft Edge Add-ons, în locul încărcării extensiei în Modul dezvoltator. Pași de configurare mai clari, în română și engleză.
  • VIZEN Connector e publicat în Chrome Web Store, pe lângă Microsoft Edge Add-ons: nu mai e nevoie de Modul dezvoltator sau de extensia neîmpachetată în Chrome, Edge sau Brave.
  • Actualizări: installerul descărcat pentru o actualizare se șterge după ce pornește versiunea nouă, așa că nu mai ocupă 56 MB.
  • Copia din Microsoft Store: nu cere nicio permisiune specială în afară de rularea ca aplicație desktop, iar intrarea ei „Pornire la conectare” dispare odată cu aplicația.
0.4.618 octombrie 2026
  • Actualizări automate (Setări → Actualizări): VIZEN verifică vizen.ro și GitHub, verifică fiecare actualizare și o instalează doar când confirmi. Setările și datele se păstrează. Instalează o dată manual versiunea 0.4.6; următoarele vin singure.
  • Microsoft Store: VIZEN e disponibil în Microsoft Store; copia din Store e actualizată de Store.
0.4.518 octombrie 2026
  • VIZEN Connector din Microsoft Edge Add-ons (și din Chrome Web Store, după aprobare) funcționează cu VIZEN. O conexiune existentă se actualizează automat.
0.4.418 octombrie 2026Prima versiune publică
  • Overlay-uri din orice fereastră sau zonă decupată, peste jocurile în fereastră și fără margini, cu click-through, transparență și performanță măsurată.
  • Modul Apeluri: apelurile din Discord, Zoom, Teams, WhatsApp și browser sunt detectate; decupezi fiecare participant.
  • Studio / OBS: ferestre curate pentru OBS, compoziții, straturi media și programări pentru sponsori.
  • Smart Notes, Smart Draw și Smart Audio Mixer cu Smart Audio Focus.
  • Taburi din browser cu extensia VIZEN Connector: treci la orice tab, îl pui pe mute, îl muți sau îl oglindești live.
  • Engleză și română, temă întunecată și luminoasă. Gratuit și open source, sub licența GNU GPL v3.
