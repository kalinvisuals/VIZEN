04 — Game safety

Overlays without touching your game.

VIZEN's overlays are ordinary always-on-top windows, like the ones Discord, Steam or NVIDIA show.

What VIZEN uses


  • Windows Graphics Capture, the public API of the Snipping Tool and OBS
  • Ordinary topmost windows for overlays
  • Windows audio sessions for per-app volume
  • Registered hotkeys, no keyboard hooks

What VIZEN never does


  • Inject code or DLLs into games
  • Read or write game memory
  • Bypass anti-cheat or DRM
  • Automate input or send data anywhere

Run games in windowed or borderless mode. No one can promise how every anti-cheat decides; VIZEN does none of the things they ban for.

Free and open source

No ads. No account. No tracking.

VIZEN is free software under the GNU GPL v3. Anyone can read the code, check what it does and help make it better.

FAQ

Questions

Is VIZEN really free?

Yes. VIZEN is free and open source (GNU GPL v3), with no ads, no account and no paid features.

Does it work with fullscreen games?

It works with windowed and borderless (fullscreen windowed) games. Exclusive fullscreen draws directly to the screen, so no window can appear over it without injecting into the game, which VIZEN never does. VIZEN tells you when it detects exclusive fullscreen.

Can it get me banned?

VIZEN never touches the game: no injection, no memory access, no input automation. Its overlays are normal windows, like Discord's or Steam's. Nobody can guarantee every anti-cheat decision, but VIZEN does none of the things they are known to ban for.

Does VIZEN collect my data?

No. There is no telemetry and no account; settings stay in your user folder. See the privacy policy.

How do updates work?

The Microsoft Store version updates through the Store. The installer version checks vizen.ro and GitHub, verifies the digital signature and the file, and installs only after you confirm.
