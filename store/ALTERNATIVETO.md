## Short description (tagline)

Free, open-source live overlays for Windows: any window or cropped region on top of your game or in OBS.

## Description

VIZEN turns any window into a live overlay. Pick a live chat, a video, a web page or a part of a game, crop the area
you need, and keep it on top of your windowed or borderless game, in a clean window for OBS, or in a composition.

Gaming overlays: live, always-on-top copies of any window or region, with opacity, click-through and one-key show /
hide. A measured performance readout shows the real frame rate, dropped frames and latency of every capture.

Studio / OBS: clean output windows for OBS Window Capture with exact pixel sizes, fit / fill / stretch and a chroma-key
background. Compositions combine several captures, logos, GIFs and videos into one window, and schedules show sponsor
logos automatically.

Smart tools: Smart Draw (arrows, shapes and text over anything, with pass-through), Smart Notes (notes and checklists
that float over games), and the Smart Audio Mixer with a volume for every app, profiles, a floating mixer and Smart
Audio Focus, which lowers your music while friends talk.

Browser tabs: with the optional VIZEN Connector extension for Chrome, Edge and Brave, every tab becomes its own source,
and a tab can be mirrored live even while it is in the background.

Game-safe by design: no DLL injection, no game memory access, no anti-cheat bypass; it uses only public Windows APIs
(Windows Graphics Capture, the same API as the Snipping Tool and OBS). No account, no telemetry, everything stays on
your PC. Exclusive fullscreen games are not supported (switch them to borderless).

## Alternative to

Suggest VIZEN as an alternative to apps that do the same main job (a live copy of a window on top):

- **OnTopReplica** (live clone of a window or region, always on top) — closest match
- **WindowTop** (always on top, picture-in-picture of windows)
- **PiP-Tool** (picture-in-picture for Windows)
- **Overwolf** (in-game overlays) — only the overlay part, VIZEN has no app store
